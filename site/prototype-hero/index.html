All your Claude Code agents,
in one window.

          

            Orchestrate runs Claude Code agents side by side, each in its own Git worktree, so they
            never step on each other. Watch them work, nudge them when they drift, and merge the work
            you want to keep.
          

          

          
Free and open source · Needs Claude Code installed and logged in

        

        
      

    


    
    

      

        

          

            
All your Claude Code agents,
in one window.

            
Every project, every agent, and what each one is doing right now.

            Scroll ↓
          

          

            01
            
Watch every agent work, live.

            
Each one runs the real claude CLI under your own login, in its own worktree and branch. Your checkout stays untouched.

          

          

            02
            
Send a follow-up anytime.
It waits its turn.

            
Stop an agent mid-turn, correct it, or queue up what's next while it's still busy.

          

          

            03
            
Review the changes.
Keep what you like.

            
Everything an agent changed, as one diff. Nothing lands in your project until you merge it.

          

          

            04
            
Merge it in one click.

            
If it conflicts, a separate agent resolves it in its own worktree, so your project is never left half-merged.

          

          

            05
            
Now it's yours.

            
The window is live. Click around, send an agent a follow-up, start a new one.
